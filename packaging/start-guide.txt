RefArchive 0.7.0 — Windows 10/11 64비트

1. 설치 후 바탕화면의 RefArchive를 실행하세요. Python 설치는 필요 없습니다.
2. '+ 자료 추가'로 이미지·동영상·PDF·Office 문서·텍스트를 등록하세요. URL은 '링크 저장'을 사용하세요.
3. 키워드는 자료의 특징, 카테고리는 자료를 모으는 큰 분류입니다.
4. 카테고리를 먼저 만들면 새 자료를 자동 배정합니다. 분류 기준에서 포함·제외 문구를 설정하고 확인함에서 결과를 승인하세요.
   등록일별 묶음 보기가 기본이며 날짜별 모아 보기에서 바꿀 수 있습니다.
5. 키워드 관리의 텍스트 규칙으로 제목·파일명·메모·본문의 문구를 분류할 수 있습니다.
   텍스트 규칙은 사례가 필요 없고, 이미지 유사도 분류만 확정 이미지 10개가 필요합니다.
6. 이미지 키워드 분류 모델은 사용자가 준비할 때 약 88.6 MB 다운로드합니다.
   일반 저장·검색에는 인터넷이 필요 없습니다. OCR는 Windows 언어팩이 필요합니다.
7. 업로드 창의 저장 방식에서 '새 묶음'을 선택하면 여러 파일을 한 자료로 보관합니다.
8. 큰 분석 표시는 ×로 닫고 작은 상태 버튼으로 다시 열 수 있습니다.
   닫아도 분석은 계속됩니다. MP4·WebM은 자료 상세에서 재생합니다.

프로그램 종료: 화면의 '보관 · 백업'에서 '프로그램 종료'를 누르세요.
브라우저 탭만 닫으면 서버는 계속 실행됩니다.
업데이트나 제거 전에 위 방법으로 프로그램을 종료하세요. 분석 중에는 기다리세요.

자료 위치: %LOCALAPPDATA%\RefArchive\data\library
모델 위치: %LOCALAPPDATA%\RefArchive\models
실행 기록: %LOCALAPPDATA%\RefArchive\data\logs
업데이트·프로그램 제거 시 개인 자료는 삭제하지 않습니다.

이전 프로젝트의 자료를 옮기려면 기존 앱에서 ZIP 백업을 만든 뒤
새 앱의 '보관 · 백업'에서 복원하세요. 복원은 현재 자료함을 교체합니다.
설치형과 압축 해제형은 같은 Windows 계정의 같은 자료함을 사용합니다.
압축 해제형을 다른 PC로 복사해도 자료는 이동하지 않습니다. ZIP 백업을 사용하세요.

압축 해제형: ZIP 전체를 풀고 폴더의 RefArchive.exe를 실행하세요.
RefArchive.exe만 다른 곳으로 옮기면 필요한 파일이 없어 실행되지 않습니다.
실행 실패 시 표시된 실행 기록과 Windows OCR 언어팩을 확인하세요.

상세 사용법: '사용설명서.html'을 더블클릭하거나 앱 상단의 '사용법'을 누르세요.
설치·자료 이동 안내: '배포안내.html'을 더블클릭하세요.
인터넷이나 프로그램 실행 없이도 기본 브라우저에서 안내를 읽을 수 있습니다.
개인 자료와 테스트 이미지는 이 배포본에 포함하지 않았습니다.

여러 파일을 한 카드로 저장: 자료 추가에서 저장 방식의 묶음을 선택하세요.
기존 파일은 여러 자료 선택 후 하나로 묶기, 상세에서 묶음 풀기를 사용하세요.
모음은 폴더형 정리, 묶음은 여러 파일을 한 자료로 보관하는 기능입니다.

0.5.0 새 기능
- DOCX·XLSX·PPTX·TXT·MD·CSV·TSV·LOG를 보관하고 본문 텍스트로 검색합니다.
  미리보기는 텍스트만 표시하며 매크로·암호화·구형 Office 문서는 지원하지 않습니다.
- 자료 날짜를 등록일과 별도로 입력하고 날짜순 정렬·연도/연월 그룹·기간 필터를 사용합니다.
  날짜를 모르는 기존 자료는 미지정으로 유지합니다.
- 연결된 앱으로 복사본을 열 수 있습니다. 수정은 자료함 원본에 자동 반영되지 않습니다.
  수식·필드·외부 연결·첨부 등과 CSV·TSV는 연결 앱 열기를 제한합니다.
- 기존 자료함은 스키마 v5로 변환합니다. 새 자료함·백업은 구형 앱으로 열 수 없으므로
  업데이트 전 ZIP 백업을 보관하세요. 자세한 형식 한계는 사용설명서를 참고하세요.

0.4.1 수정
- 백업 파일의 정보만 확인해도 다운로드 권한이 소모되던 문제를 수정했습니다.
  파일 정보 확인 후에도 ZIP을 한 번 다운로드할 수 있습니다.

0.4.0 새 기능
- 묶음 상세에서 대표 파일 지정, 앞뒤 순서 변경, 선택 파일만 분리합니다.
- 보관 · 백업에서 백업 폴더와 하루 한 번 자동 백업을 설정합니다.
  앱이 실행 중일 때만 동작하며 백업 ZIP과 압축 해제 총량 각각 최대 50 GiB입니다.
  백업은 자동 삭제하지 않습니다. 완료한 ZIP은 지정 폴더에 보관됩니다.
- 유사 중복 검사 후 두 원본을 비교해 한 파일만 휴지통으로 옮깁니다.
- 실행 버전, 진단 보고서, 다른 PC 배포 점검표를 보관 · 백업에서 확인합니다.

ZIP 업데이트 받기
새 ZIP은 새 폴더에 압축을 풀어 주세요. 0.4.0 이상에서는 '받은 버전 정보 확인'으로
새 폴더의 '업데이트 정보.json'을 선택해 버전을 비교할 수 있습니다.
먼저 백업하고 기존 앱의 '프로그램 종료'를 누른 다음 새 EXE를 실행하세요.
같은 PC·Windows 계정이면 기존 배포본의 자료를 다시 올릴 필요가 없습니다.
자료를 확인할 때까지 이전 프로그램 폴더를 보관하세요.
