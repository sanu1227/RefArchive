# RefArchive

> 공개 소스 저장소입니다. 개인 데이터, 로그인 정보, 환경 설정, 로컬 실행 파일, 빌드 결과물과 실제 사용자 화면 캡처는 포함하지 않습니다. 원본 로컬 Git 이력을 가져오지 않은 현재 소스 스냅샷입니다.

> 0.7.0은 만든 카테고리에 제목·본문·확정 사례를 기준으로 자료를 자동 배정하고 등록일별로 묶어 표시합니다. 개발 빌드 결과는 `release/0.7.0`에 생성하며 이 소스 저장소에는 포함하지 않습니다. 아래 고정 링크에서 최신 공개 버전을 받으세요. 설치된 앱은 새 설치파일을 실행해야 업데이트됩니다.

이미지·동영상·PDF·링크를 로컬에 보관하고 여러 카테고리와 키워드로 검색하는 개인 자료함입니다.

## 실행

### 공유용 Windows 배포본

[최신 설치파일 다운로드](https://github.com/sanu1227/RefArchive-releases/releases/latest/download/RefArchive-Setup-x64.exe) · [ZIP 다운로드](https://github.com/sanu1227/RefArchive-releases/releases/latest/download/RefArchive-Portable-x64.zip) · [변경 내용](https://github.com/sanu1227/RefArchive-releases/releases/latest)

온라인 배포는 공개 전용 저장소 `sanu1227/RefArchive-releases`에서 제공합니다. 설치형을 기본 다운로드로 안내합니다. 이번 로컬 빌드의 `release/0.7.0/온라인 배포` 안에 있는 설치파일·ZIP·버전 정보·체크섬 네 파일을 새 정식 릴리스에 올리면 같은 링크가 최신 버전을 제공합니다. 자세한 절차는 [배포 안내](docs/distribution.md)를 참고하세요.

`release/0.7.0/RefArchive-0.7.0-Setup-x64.exe` 또는 고정 설치파일 링크를 전달하세요. Windows 10/11 64비트에서 실행해 설치하며 Python 설치가 필요 없습니다. 업데이트할 때는 기존 앱을 종료하고 새 설치파일을 실행합니다. 설치 없이 실행하려면 `release/0.7.0/RefArchive-0.7.0-Portable-x64.zip` 전체를 풀고 `RefArchive.exe`를 실행하세요. 웹 화면은 브라우저에 열리며 같은 PC에서만 접속합니다.

자료는 `%LOCALAPPDATA%\RefArchive\data\library`, 모델은 `%LOCALAPPDATA%\RefArchive\models`에 보관합니다. 업데이트·제거 시 개인 자료를 삭제하지 않습니다. 개발용 자료함과 별개이며 기존 자료는 앱의 ZIP 백업·복원으로 옮깁니다. [배포 안내](docs/distribution.md)를 참고하세요.

받는 사람은 앱 상단의 **사용법** 또는 시작 메뉴의 안내 바로가기를 누르면 됩니다. 배포 폴더의 **사용설명서.html**, **배포안내.html**은 더블클릭해서 인터넷·프로그램 실행 없이 읽을 수 있습니다. MD는 개발용 원본이며 사용자 안내에는 HTML과 첫 실행 TXT를 제공합니다.

### 개발용 소스 실행

Windows에서 **`start.cmd`를 더블클릭**하세요. Python 3.12 이상이 필요합니다. 첫 실행은 프로젝트 전용 `.venv`를 만들고 필요한 라이브러리를 설치하므로 인터넷 연결이 필요합니다. 이후 자료 저장·검색은 오프라인으로 사용할 수 있습니다.

기본 주소: `http://127.0.0.1:18765`

현재 버전은 로컬 서버와 브라우저 화면으로 구성합니다. `start.cmd`는 서버를 백그라운드로 실행하고 브라우저를 엽니다. 실행 창을 유지할 필요가 없습니다. `보관 · 백업`에서 바탕화면 바로가기를 만들거나 프로그램을 종료할 수 있습니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

개발용으로 실행 창을 유지하려면 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -NoBrowser`를 사용합니다. 이 모드는 `Ctrl+C`로 종료합니다.

직접 실행:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe archive.py --open
```

다른 저장 위치 또는 포트:

```powershell
.\.venv\Scripts\python.exe archive.py --data "D:\RefArchiveData" --port 18766 --open
```

한 자료함에 서버를 여러 개 실행하지 마세요. 외부 접속을 허용하지 않으며 `127.0.0.1`에서만 사용합니다.

기본 포트에서 RefArchive가 이미 실행 중이면 기존 앱을 엽니다. 다른 프로그램이 해당 포트를 사용하면 다른 포트를 지정하세요.

## 현재 기능

- 제목·파일명·메모·추출 본문에 지정 문구가 포함되면 키워드 추천·자동 적용. 사례 없이 사용하며 하나라도/모두 포함, 일치 근거, 문서 유형별 재분류를 지원.

- 여러 파일을 카드 하나로 보관하는 묶음 자료. 새 묶음 업로드·기존 자료 묶기·파일 전환·기존 묶음 추가·묶음 풀기. 검색·휴지통·백업에 반영.

- JPG·PNG·정지 WebP·PDF·MP4·WebM 업로드와 드래그, 이미지 클립보드 붙여넣기. 이미지·PDF 최대 50 MB, 동영상 최대 200 MB. 이미지는 최대 4천만 픽셀, PDF는 암호 없는 1~300페이지.
- 동영상 상세 재생·시간 탐색·원본 저장. 동영상은 재생 아이콘을 표시하며 자동 이미지 분류·OCR 사례에서 제외.
- 새 모음·기존 모음으로 혼합 업로드, 파일별 제외와 실패 파일 재시도, 모음 바로 탐색.
- 접고 다시 여는 분석 표시, 접은 상태 유지, 유형별 탐색과 상세 검색을 분리한 반응형 갤러리.
- 원본 복사 저장, 별도 미리보기. 원본 파일 바이트 보존.
- 여러 카테고리·키워드 지정, 공통 분류 일괄 적용, 미분류함.
- 제목·파일명·메모·출처·키워드·추출 텍스트 검색, 키워드 모두/하나 이상 포함, 제외 키워드.
- 자료 상세 편집, 즐겨찾기, 정렬, 링크와 출처 저장.
- 동일 파일 SHA-256 확인. 중복 이미지에는 기존 키워드·카테고리에 새 분류만 추가하고 제목·메모·출처는 덮어쓰지 않음.
- 키워드·카테고리 추가·이름 변경·병합·삭제. 분류 삭제는 원본 삭제와 구분.
- 목록 및 자료 상세 상단에서 휴지통 이동·복원. 영구 삭제는 현재 지원하지 않음.
- 전체 ZIP 백업·복원, 메타데이터 JSON 내보내기.
- 검색 조건 저장·재적용·변경·삭제. 조건에 맞는 새 자료도 포함.
- 모음 생성·이름 변경·추가·제외·삭제, 이미지 2~6개 비교.
- 키워드별 `끄기 / 추천만 / 자동 적용`, 유사도 기준, 설정 저장 완료 후 재분류, 확인 전 자동 결과 갱신, 분류 확인함과 승인·거절 기록.
- 미분류·분류 이력 없는 새 자료·전체·검색 결과·선택 자료에 유형·키워드·카테고리·최근 N시간 조건을 결합한 분류 범위와 대상 파일 개수 확인.
- 로컬 CLIP 이미지 분석과 최대 30개 유사 이미지 검색. 모델 최초 준비 시 약 88.6 MB 다운로드, 준비 후 원본의 외부 전송 없이 처리.
- PDF 페이지별 텍스트 추출, Windows OCR, 추출 텍스트 수정, 근거 페이지 연결, 원문 문장 추출 요약·키워드 후보.
- 새 자료 자동 요약·자동 OCR 설정. 기본은 끄기이며 키워드 자동 분류와 별도로 설정.
- 링크 이미지 가져오기 설정. 공개 HTML의 img·대표 이미지 및 직접 이미지 링크에서 사용자가 선택한 정지 이미지를 저장. 기본은 끄기.
- 키워드별 확정 이미지 10개 최소 조건. PDF·링크·휴지통·확인 전 자동 결과는 사례 수에서 제외.

자동 분류는 확정 사례 중 유사한 3개의 CLIP 코사인 유사도 평균으로 판단합니다. 기본 기준은 0.9이며 0.5~1로 조정할 수 있습니다. 10개는 활성화 조건이며 정확도 보장이 아닙니다. 자동 적용 결과는 승인 전까지 사례로 재사용하지 않습니다. 사례가 10개 미만으로 줄면 새 분류를 중단하고 기존 결과는 보존합니다. 거절한 자료·키워드 조합은 재분석으로 다시 붙이지 않습니다.

요약은 원문에서 최대 5개 문장을 고르는 방식입니다. 생성형 AI 요약이나 정교한 한국어 형태소 분석은 제공하지 않습니다. OCR는 Windows에 설치된 언어팩을 사용하며 스캔 PDF는 최대 30페이지까지 처리합니다. 로그인·다운로드 제한 우회, 외부 링크의 영상 다운로드, 클라우드 동기화는 제공하지 않습니다.

## 데이터와 복원

개발용 데이터: `data/library/`. 배포본은 `%LOCALAPPDATA%\RefArchive\data\library`를 사용합니다.

- `archive.sqlite3`: 자료·키워드·카테고리·메모·즐겨찾기·저장 검색·모음·분류 설정·검토 기록·내용 분석 결과.
- `files/`: 원본 파일. 원래 파일명은 데이터베이스에서 보관.
- `thumbs/`: 480px 이내 미리보기.

`보관 · 백업`에서 ZIP을 저장하면 원본·미리보기·SQLite·JSON·휴지통 자료를 포함합니다. JSON 내보내기에는 원본 파일이 없으므로 복구용으로는 ZIP을 사용하세요. ZIP을 다른 디스크에도 보관하는 것을 권장합니다.

복원은 백업의 자료함으로 **현재 자료함을 교체**합니다. 경로·DB 구조·무결성·원본 체크섬·이미지/PDF/영상 컨테이너 형식을 검사합니다. 실패하면 교체하지 않습니다. 교체 직전 자료함은 `data/backups/before-restore-*.zip`과 `data/previous-*/`에 보관합니다. 안전 백업 ZIP을 다시 복원해 되돌릴 수 있습니다. 이 파일들은 자동 삭제하지 않습니다.

백업 ZIP과 압축 해제 총량은 각각 최대 50 GiB, 내부 파일은 최대 50,000개입니다. 파일 기반 ZIP64 백업과 스트리밍 업로드·다운로드를 사용합니다. 앱 실행 중 하루 한 번 자동 백업을 선택할 수 있습니다. 백업 파일은 자동 삭제하지 않습니다.

예전 버전의 자료함과 백업은 새 데이터베이스 형식으로 변환합니다. 최초 변환 전 DB 사본은 데이터 폴더의 `backups/migration-v1-*.sqlite3` 또는 `backups/migration-v2-*.sqlite3`·`backups/migration-v3-*.sqlite3`·`backups/migration-v4-*.sqlite3`에 남깁니다. 이 사본은 DB만 포함하며 전체 복구용으로는 ZIP을 사용하세요. 모델은 개발용 `.models/`, 배포본 `%LOCALAPPDATA%\RefArchive\models`에 별도 보관하며 백업에 포함하지 않습니다. 다른 PC에서 분석하려면 모델을 다시 준비하세요. 분석 중에는 자료함 교체와 프로그램 종료를 막습니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node tests/test_job_status.cjs
```

테스트는 임시 폴더에서 실행하며 실제 자료함을 변경하지 않습니다. 화면 검증과 상세 결과는 `docs/development-log.md`에 기록합니다.

분석 상태·설정 저장·분류 범위 화면 로직 검증은 개발용 Node.js가 필요합니다. 앱 실행에는 Node.js가 필요하지 않습니다.

## 0.4.0 보관 개선

묶음 대표 파일·순서·개별 분리, 파일 기반 대용량 백업·스트리밍 복원, 앱 실행 중 하루 한 번 자동 백업, 로컬 유사 중복 비교와 개별 휴지통 이동을 제공합니다. 보관 · 백업에서 버전·진단 보고서·배포 점검표를 확인합니다. 직접 전달받은 ZIP의 `업데이트 정보.json`으로 버전을 비교하며 원격 업데이트 조회나 자동 설치는 하지 않습니다. 자동 백업 경로와 점검표는 해당 PC의 `data/maintenance.json`에 저장하고 자료함 백업에는 포함하지 않습니다.

## 문서와 자료 날짜 (0.5.0)

- DOCX·XLSX·PPTX·TXT·MD·CSV·TSV·LOG 원본 보관, 기존 분류·모음·묶음·검색·백업 통합. 표준 라이브러리로 텍스트만 추출하고 새 런타임 의존성은 추가하지 않았습니다.
- 문서 텍스트 미리보기·검색은 50만 자까지. Office는 압축 해제 100 MB / 2,000항목 / XML당 10 MB 한도. 서식·이미지·차트·수식 계산은 제공하지 않습니다.
- Windows 기본 앱으로 별도 복사본 열기. 매크로·구형·암호화 형식은 지원하지 않으며 외부 연결·필드·수식·첨부 등과 CSV·TSV는 연결 앱 열기를 제한합니다. 상세에서 이유를 확인할 수 있습니다.
- 등록일과 별도인 선택 자료 날짜, 편집·삭제, 날짜순 정렬, 연도·연월 그룹, 기간 필터, 저장 검색. 기존 날짜가 없는 자료는 미지정으로 유지합니다.
- v1~v4 DB·백업을 v5로 이전하고 원본과 기존 메타데이터를 보존합니다. 상세한 묶음 날짜 규칙과 형식 한계는 [사용설명서](docs/user-guide.md)를 참고하세요.

추가 검증: `node tests/test_documents_dates.cjs`. 전체 Python 회귀는 기존 `python -m unittest discover -s tests -v`에 포함됩니다. 로컬 검증에서는 실제 자료함과 분리한 `--data` 경로를 사용하며 실제 설치본을 교체하지 않습니다.

## 0.7.0 카테고리 자동 배정

기존 카테고리의 이름·설명·포함/제외 문구와 확정 사례를 로컬에서 비교합니다. 확실한 후보 하나만 자동 배정하고 경합·약한 근거는 확인함에 추천합니다. 수동 분류와 승인·거절을 보존하며 등록일 그룹을 제공합니다. 설치파일과 HTML 사용법은 `release/0.7.0`에 생성합니다. 공개 버전은 아래 고정 링크와 릴리스 페이지에서 확인하세요.

## 테스트 준비

전체 테스트는 선택적 CLIP 분석 모델이 준비된 개발 환경을 사용합니다. 앱의 보관·백업 화면에서 로컬 모델을 준비한 뒤 가상 환경에서 `python -m unittest discover -s tests -v`를 실행합니다. 모델 파일은 `.models/`에만 두며 Git에는 올리지 않습니다.
