RefArchive 사용설명서

RefArchive는 이미지·동영상·PDF·Office 문서·텍스트·링크를 PC에 보관하고, 키워드와 카테고리로 다시 찾는 개인 자료함입니다. 이 설명서는 현재 구현된 버전의 실행, 자료 등록, 검색, 정리, 백업과 복원 방법을 안내합니다.

카테고리를 먼저 만들면 새 자료의 제목·본문 등을 비교해 적합한 카테고리에 자동 배정합니다. 키워드도 직접 입력하거나 자동 분류를 켤 수 있습니다. PDF·OCR 텍스트와 요약 결과도 검색에 활용할 수 있습니다.

앱 상단의 사용법, 시작 메뉴의 RefArchive 사용설명서, 또는 배포 폴더의 user-guide.html을 열면 이 안내를 브라우저에서 읽을 수 있습니다. 목차를 누르면 해당 항목으로 이동합니다. 프로그램이 꺼져 있거나 인터넷이 없어도 HTML 파일로 읽을 수 있습니다.

버전 안내: 제목·본문 텍스트 규칙은 0.6.0부터, Office·텍스트 문서 지원과 자료 날짜 기능은 0.5.0부터 제공합니다. 카테고리 자동 배정·등록일 그룹은 0.7.0부터 제공합니다. 아래 고정 다운로드 링크에서 최신 공개 버전을 받을 수 있습니다. 받은 설치파일·ZIP의 버전은 릴리스 페이지에서 확인하세요. 앱의 실행 버전은 보관 · 백업에서 확인할 수 있습니다.

카테고리 자동 배정과 정확도 높이기

  1. 키워드 · 카테고리 관리에서 회의록, 계약, 교육처럼 용도가 구분되는 카테고리를 만듭니다. 새 카테고리는 기본적으로 자동 배정입니다. 기존 자료를 즉시 변경하지 않으며, 다음 업로드부터 적용합니다.
  2. 각 카테고리의 분류 기준을 엽니다. 설명에 어떤 자료를 넣을지 적고, 실제 제목·본문에서 쓰는 포함 문구와 혼동을 막을 제외 문구를 입력합니다. 한 줄에 한 문구를 입력하며 각각 최대 30개, 문구당 100자입니다.
  3. 자료를 올리면 제목·파일명·메모·추출된 본문을 비교합니다. 이름만으로 시작할 수 있으며 이미지 10개나 별도 모델은 필요 없습니다. 직접 카테고리를 지정한 자료는 그 분류를 우선합니다.
  4. 분류 확인함에서 배정 근거와 후보를 확인하고 승인·거절합니다. 승인한 자료와 직접 지정한 자료는 다음 분류의 비교 사례로 쓰입니다. 확인 전 자동 결과는 사례로 쓰지 않습니다.
  5. 설정을 변경한 뒤 기존 자료에는 분류 확인함 → 대상 선택 → 이 범위로 다시 분류를 실행합니다. 이미 분류된 자료를 바꾸려면 전체 자료, 현재 선택한 자료 또는 해당 카테고리 조건을 사용하세요. 카테고리 미지정 자료 범위에는 이미 배정된 자료가 포함되지 않습니다.

정확도를 높이는 설정 예시

카테고리 포함 문구 제외 문구
회의록 회의록, 회의 결과, 의사록 회의실 예약, 예시 양식
체결 계약 계약서, 체결 완료 미체결, 초안, 양식
교육 자료 강의, 수업 자료, 실습 과제 광고, 수강료 영수증

표의 쉼표로 나눈 항목은 설정창에서 각각 별도 줄에 넣습니다. 제외 문구는 어느 항목에서든 발견되면 해당 카테고리 후보를 제외하므로 너무 흔한 단어는 피하세요. 자연어 설명은 표현을 비교하는 보조 자료이며, 명령문을 이해하고 실행하는 생성형 AI가 아닙니다.

자동 배정은 근거가 충분하고 2순위 후보와 차이가 있을 때 최대 한 카테고리에만 적용합니다. 후보가 비슷하거나 근거가 약하면 최대 세 후보를 추천하며 자료는 카테고리 미지정에 남을 수 있습니다. 두 분류가 모두 맞으면 확인함에서 각각 승인해 여러 카테고리에 넣을 수 있습니다. 자동 배정을 끄거나 추천만으로 사용할 수도 있습니다.

제목·파일명에 분류 이름이나 포함 문구가 있으면 우선합니다. 본문에 한 번 등장하는 단어는 약한 근거로 취급하며, 겹치지 않는 포함 문구 두 개가 일치하면 더 강하게 평가합니다. 확정 사례를 통한 자동 배정은 서로 다른 자료 세 개 이상과 가까운 사례 두 개의 지지를 요구합니다. 같은 묶음은 한 사례로 계산하고 대상 자신의 묶음은 비교에서 제외합니다. 최신 확정 자료 최대 20개와 각 자료 앞부분의 표현을 비교하므로 문서 전체 의미를 이해하거나 모델을 학습하는 방식은 아닙니다.

정확도는 실제 자료로 확인해야 합니다. 먼저 추천만으로 30~50개를 분류하고 맞는 후보를 승인하세요. 오분류 문구는 제외 조건으로 보완하고, 평가에 사용하지 않은 새 자료에서도 확인한 뒤 자동 배정을 켜는 방법을 권장합니다. 자동 배정 중 맞은 비율과 전체 자료 중 자동 배정한 비율을 따로 확인하세요. 추천을 보류하는 정책 때문에 모든 자료가 자동으로 채워지지는 않습니다. 화면의 유사도·판단 점수는 정확도 확률이 아닙니다.

Office·텍스트 파일의 저장된 추출 본문과 PDF 텍스트를 사용합니다. 스캔 PDF·이미지는 자동 OCR을 켜거나 먼저 OCR을 실행해야 본문을 사용할 수 있습니다. 영상의 장면·음성, 링크 웹페이지 본문은 분석하지 않으며 저장한 제목·파일명·메모를 사용합니다. 제목·메모·추출 본문을 수정했으면 다시 분류하세요.

재분류는 확인 전 자동 배정과 추천만 갱신합니다. 직접 지정·승인·거절·직접 해제한 분류와 원본은 유지합니다. 거절한 분류를 되돌리려면 자료 상세에서 카테고리를 직접 추가하세요. 이전 버전의 카테고리는 수동 분류로 보존합니다. 카테고리 설정과 이력이 포함된 백업은 0.7.0 이상에서 복원하세요.

등록일과 자료 날짜로 모아 보기

목록은 기본적으로 등록일 · 연월별로 묶어 표시합니다. 카테고리를 선택한 상태에서도 날짜 그룹이 유지됩니다. 날짜별 모아 보기에서 등록일의 일별·연월별·연도별 또는 그룹 없음을 선택하세요. 등록일은 PC의 현지 시간으로 표시합니다.

자료 날짜는 문서 작성일·촬영일 등 사용자가 자료 상세에서 정한 날짜입니다. 본문의 날짜나 파일명으로 작성일을 임의 추정하지 않습니다. 자료 날짜가 필요한 경우 직접 입력하고 자료 날짜 · 연월별/연도별을 선택하세요. 자료 날짜 검색 범위는 등록일 그룹과 별개이며, 재분류의 최근 등록 시간은 실제 등록 시각을 사용합니다. 그룹은 화면 표시 방식이며 원본 파일을 날짜 폴더로 이동하지 않습니다.

처음 실행하기

권장 다운로드는 최신 설치파일입니다. 업데이트할 때도 같은 링크에서 새 설치파일을 받아 기존 앱을 종료한 뒤 실행하세요. 기존 설치를 먼저 제거할 필요가 없습니다.

  1. Windows 10/11 64비트에서 RefArchive-0.7.0-Setup-x64.exe를 실행해 설치합니다. ZIP으로 받았다면 전체 압축을 풀고 폴더의 RefArchive.exe를 실행하세요.
  2. 바탕화면 또는 시작 메뉴의 RefArchive를 클릭합니다. 압축 해제형은 ZIP 전체를 풀고 폴더의 RefArchive.exe를 실행합니다.
  3. 브라우저가 자동으로 열리면 사용을 시작합니다. 실행 창을 열어 둘 필요가 없습니다. 다시 실행해도 같은 자료함을 엽니다.

배포본은 Python 설치가 필요 없습니다. 이미지 저장과 검색은 오프라인으로 사용할 수 있습니다. 자동 분류 모델을 처음 준비하거나 외부 링크를 열 때는 인터넷 연결이 필요합니다. 개발용 소스를 실행할 때만 Python 3.12 이상과 start.cmd를 사용하며, 첫 실행에서 라이브러리를 설치합니다.

주소만 열어서는 서버가 시작되지 않습니다. 프로그램을 종료하거나 PC를 종료한 뒤에는 RefArchive를 다시 실행하세요. 기본 주소는 http://127.0.0.1:18765/이며 배포본은 충돌 시 18766~18784 중 빈 포트를 선택합니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다. 서버를 종료하려면 보관 · 백업의 프로그램 종료를 누릅니다. 분석 중에는 작업이 끝난 뒤 종료할 수 있습니다.

설치형은 바탕화면 바로가기를 만듭니다. 압축 해제형은 보관 · 백업의 바탕화면 바로가기 만들기를 사용할 수 있습니다. 압축을 푼 폴더를 옮기면 기존 바로가기를 제거하고 새 위치에서 다시 만드세요. RefArchive.exe만 따로 옮기면 실행되지 않습니다. 개발용 start.ps1 -NoBrowser 모드에서는 실행 창을 유지하고 Ctrl+C로 종료합니다.

업데이트·제거 전에 앱에서 프로그램을 종료하세요. 설치형과 압축 해제형은 같은 Windows 계정의 자료함을 사용합니다. 자료와 모델은 설치 폴더 밖에 저장되어 업데이트·제거 후에도 유지됩니다. 프로그램을 다른 PC로 복사하면 자료는 함께 이동하지 않습니다. 기존 자료는 ZIP 백업으로 내보내 새 PC의 앱에서 복원하세요. 복원은 현재 자료함을 교체하므로 필요한 자료는 먼저 백업하세요.

여러 파일을 하나의 묶음 자료로 보관하기

  1. + 자료 추가에서 여러 파일을 선택합니다.
  2. 저장 방식을 여러 파일을 하나의 묶음으로 저장으로 바꿉니다.
  3. 묶음 제목과 공통 키워드·카테고리·메모를 입력하고 저장합니다.

목록에는 카드 1개가 나타납니다. 카드의 파일 수를 확인하고 상세 화면에서 파일 이름 버튼을 눌러 이미지·동영상·PDF·링크를 전환하세요. 선택 파일의 원본 저장, 영상 재생, PDF 열기, 내용 분석도 사용할 수 있습니다. 묶음의 제목·메모·출처는 공통 정보이며 기존 파일의 정보는 별도로 보존됩니다. 상세에서 키워드·카테고리를 저장하면 모든 파일에 같은 분류가 적용됩니다.

기존 자료는 여러 카드를 선택하고 하나로 묶기를 누릅니다. 기존 폴더형 모음도 열어서 결과 모두 선택 → 하나로 묶기로 정리할 수 있습니다. 기존 모음이 자동으로 변환되지는 않습니다. 저장 방식에서 기존 묶음을 선택하면 새 파일을 이어서 추가합니다. 묶음 풀기는 파일을 지우지 않고 개별 카드로 되돌립니다. 공통 제목·출처·메모는 각 파일의 기존 메모 뒤에 보관하며 메모 한도를 초과하면 풀기를 중단합니다.

묶음은 검색 결과와 자료 수에서 1개로 집계합니다. 내부 파일명·메모·추출 텍스트도 검색합니다. 이미지·동영상 유형 필터는 해당 파일이 들어 있는 묶음도 표시합니다. 즐겨찾기·휴지통 이동·복원은 전체 묶음에 적용됩니다. 이미지 분류와 확정 사례 10개 기준은 내부의 서로 다른 이미지 단위이며 묶음에 든 동영상·PDF·링크를 이미지 사례로 세지 않습니다.

묶음 하나는 최대 5,000개 파일을 담습니다. 동일 파일은 같은 묶음에 중복 저장하지 않습니다. 다른 묶음에 있는 파일을 다시 넣으려면 먼저 기존 묶음을 풀어야 합니다. 일부 업로드가 실패하면 성공한 파일은 한 묶음에 남고 실패한 파일만 같은 묶음에 다시 시도합니다. 전부 실패하면 빈 묶음을 만들지 않습니다.

모음은 여러 자료를 폴더처럼 모아 보는 기능이고, 묶음은 여러 파일을 카드 하나로 보관하는 기능입니다. ZIP 백업에는 묶음 관계와 모든 원본이 포함됩니다.

문서 보관과 연결 앱으로 열기

Word DOCX, Excel XLSX, PowerPoint PPTX, 일반 텍스트 TXT·MD·CSV·TSV·LOG를 다른 자료와 같은 방식으로 추가합니다. 원본 바이트를 그대로 복사하며 키워드·카테고리·모음·묶음·휴지통·ZIP 백업을 함께 사용할 수 있습니다. 문서의 추출 텍스트는 추가 즉시 검색됩니다. PDF의 기존 페이지 미리보기·텍스트 추출·OCR 기능도 유지됩니다.

문서 상세는 안전한 텍스트 미리보기입니다. 서식·그림·차트·첨부파일은 렌더링하지 않습니다. Word는 본문 문단, PowerPoint는 슬라이드 순서의 텍스트, Excel은 시트 이름·셀 주소·저장된 계산값을 표시합니다. Excel의 수식은 계산하지 않으며 날짜나 통화의 표시 서식도 재현하지 않습니다. 머리글·각주·슬라이드 노트 등은 본문 검색에 포함하지 않습니다. 추출 가능한 텍스트가 없으면 안내를 표시합니다. 미리보기와 검색은 앞 50만 자까지이며 원본은 전부 보관합니다.

일반 텍스트는 UTF-8, BOM이 있는 UTF-16, CP949를 지원합니다. 구형 DOC·XLS·PPT, RTF·ODF, 매크로 DOCM·XLSM·PPTM 및 암호화 문서는 지원하지 않습니다. 해당 앱에서 매크로 없는 DOCX·XLSX·PPTX나 PDF·TXT로 저장한 파일을 추가하세요. Office 파일은 내부 2,000개 항목, 압축 해제 크기 100 MB, XML 하나당 10 MB까지 지원합니다. 잘못된 구조·경로·DTD·엔티티가 있으면 가져오기를 거절합니다.

연결된 앱으로 복사본 열기는 Windows에 설정된 기본 앱으로 복사본을 엽니다. 해당 프로그램이 필요하며 없으면 원본 저장을 이용할 수 있습니다. 보관 원본은 변경되지 않습니다. 열린 복사본의 수정 내용을 보관하려면 다시 파일로 추가하세요. 복사본은 데이터 폴더의 opened에 남고 자료함 ZIP 백업에는 들어가지 않습니다. 필요한 수정을 별도로 저장한 뒤 오래된 복사본을 직접 정리할 수 있습니다.

외부 연결·수식·필드·첨부·바이너리 구성요소가 감지된 Office 문서와 CSV·TSV는 연결 앱 열기를 제한하고 그 이유를 표시합니다. 이 자료들도 원본 저장과 텍스트 미리보기·검색은 가능합니다. 매크로는 가져오기 단계에서 거절합니다. RefArchive는 수식·매크로·첨부파일을 실행하거나 외부 콘텐츠를 내려받지 않습니다.

자료 날짜로 정리하기

등록창 또는 자료 상세에서 자료 날짜를 입력합니다. 제작일·발행일 등 직접 확인한 날짜를 적는 선택 항목이며 등록일과 별개입니다. 입력 범위는 0001-01-01~9999-12-31의 실제 날짜입니다. 비우면 날짜 미지정으로 보관하며 기존 자료에 등록일을 대신 넣지 않습니다. 날짜를 고쳐도 등록일과 원본 파일은 바뀌지 않습니다.

  • 자료 날짜 최신순 / 오래된순: 자료 날짜로 정렬하고 미지정 자료는 항상 마지막에 둡니다. 기존 등록일 최신순 / 오래된순과 제목순도 선택할 수 있습니다.
  • 날짜별 모아 보기 → 연도별 / 연월별: 연도 또는 연월 구획을 만들고 마지막에 날짜 미지정을 표시합니다. 날짜 오래된순에서는 구획도 오름차순, 나머지는 최신 구획부터 표시합니다. 구획 안에서는 선택한 정렬을 유지합니다.
  • 상세 검색 → 자료 날짜 시작 / 끝: 양 끝 날짜를 포함하는 기간을 필터링합니다. 한쪽만 입력해도 되며 기간을 지정하면 미지정 자료는 제외합니다. 시작일이 종료일보다 늦으면 오류 안내와 빈 결과를 표시합니다.
  • 날짜 조건·정렬·그룹은 현재 조건 저장으로 다른 검색 조건과 함께 보관할 수 있습니다. 조건 초기화는 날짜 조건도 지웁니다.

여러 파일을 새 묶음으로 업로드할 때 입력한 날짜는 각 파일과 묶음에 적용됩니다. 기존 파일을 나중에 묶으면 공통 날짜는 미지정으로 시작하며 상세에서 별도로 입력합니다. 기존 묶음에 파일을 추가해도 묶음 날짜는 덮어쓰지 않습니다. 묶음 카드는 공통 날짜로 필터링·정렬하며 내부 파일의 날짜는 따로 보존됩니다. 묶음을 풀거나 파일을 분리하면 원래 파일 날짜를 유지하고 공통 날짜를 메모에 남깁니다.

이 변경에서 자료함 스키마는 v5가 됩니다. v1~v4를 처음 열 때 원래 DB의 안전 복사본을 남기고 기존 자료는 날짜 미지정으로 이전합니다. 구버전 ZIP 백업도 복원할 수 있습니다. 문서·자료 날짜·저장 검색 조건은 새 ZIP 백업에 포함됩니다. v5 자료함과 새 백업을 구형 앱으로 여는 것은 지원하지 않으므로, 실제 자료함 적용 전 백업을 보관하세요.

첫 자료 등록하기

  1. 화면 오른쪽 위의 + 자료 추가를 누릅니다.
  2. 이미지, 동영상, PDF, Office 문서 또는 텍스트 파일을 선택합니다. 여러 파일을 함께 선택할 수 있습니다.
  3. 공통 키워드에 숲, 배경, 역광처럼 쉼표로 구분해 입력합니다.
  4. 공통 카테고리에 환경, 그림 참고처럼 입력합니다.
  5. 필요한 경우 출처 URL과 메모를 입력합니다.
  6. 자료 저장을 누릅니다.

한 번에 선택한 자료에는 같은 키워드, 카테고리, 출처와 메모가 적용됩니다. 파일별로 다른 정보를 넣으려면 저장 후 각 자료의 상세 화면에서 수정하세요. 키워드를 비워 두면 미분류함에서도 찾을 수 있습니다.

지원 형식은 JPG, PNG, 정지 WebP, PDF, MP4, WebM, DOCX, XLSX, PPTX, TXT, MD, CSV, TSV, LOG입니다. 이미지·PDF·문서는 파일당 최대 50 MB, 동영상은 최대 200 MB입니다. 이미지는 최대 4천만 픽셀, PDF는 암호 없는 1~300페이지입니다. GIF·움직이는 WebP, AVI·MOV는 지원하지 않습니다. 동영상도 같은 등록창에서 추가합니다.

지원하는 파일을 화면에 끌어 놓아도 등록할 수 있습니다. 클립보드에 이미지가 있다면 편집창을 닫고 입력칸 바깥에서 Ctrl+V로 붙여넣을 수 있습니다. 드래그와 붙여넣기 동작은 브라우저와 클립보드 내용에 따라 달라질 수 있습니다.

여러 자료를 모음으로 업로드하기

  1. + 자료 추가에서 함께 보관할 이미지·동영상·PDF를 선택합니다.
  2. 파일 목록에서 이름·크기를 확인합니다. ×는 업로드 목록에서만 제외합니다.
  3. 모음에 추가 (선택)에서 + 새 모음 만들기를 선택하고 이름을 입력하거나 기존 모음을 선택합니다.
  4. 자료 저장을 누릅니다. 완료하면 해당 모음이 열립니다.

모음을 보고 있을 때 자료를 추가하면 그 모음이 기본 선택됩니다. 모음 없이 저장도 가능합니다. 일부 파일이 실패하면 성공한 자료는 모음에 남고 실패한 파일만 재시도합니다. 모든 파일이 실패하면 빈 모음을 만들지 않습니다. 모음당 최대 5,000개 파일(묶음 내부 포함)을 지원합니다. 기존 폴더형 그룹은 모음으로 표시됩니다.

모음은 프로젝트처럼 함께 보고 싶은 자료를 모은 묶음입니다. 카테고리는 큰 주제, 키워드는 검색할 특징으로 함께 사용할 수 있습니다. 한 자료는 여러 모음에 들어갈 수 있으며 원본을 중복 복사하지 않습니다. 왼쪽 모음 목록으로 바로 열 수 있습니다.

동영상 보기

동영상 카드를 누르면 상세 화면에서 재생·일시 정지·시간 탐색·전체 화면을 사용할 수 있습니다. 자동 재생하지 않으며 상세 창을 닫으면 재생이 멈춥니다. 동영상 원본 저장으로 파일을 내려받을 수 있습니다. 목록에서는 재생 아이콘을 표시하며 영상 프레임 미리보기는 생성하지 않습니다.

브라우저가 지원하는 코덱의 MP4·WebM을 재생합니다. H.264 MP4 또는 VP8·VP9 WebM을 사용할 수 있습니다. 지원하지 않는 코덱이나 손상된 영상은 안내가 나오며 원본 파일을 플레이어로 열 수 있습니다. 서버는 파일의 컨테이너 구조를 확인하지만 모든 프레임을 디코딩하거나 변환하지 않습니다. 지원 형식 참고

동영상은 수동 키워드·카테고리·모음, 검색, 즐겨찾기, 휴지통과 ZIP 백업을 지원합니다. 자동 이미지 분류, 이미지 사례 10개 조건, 유사 이미지·OCR 대상에는 포함하지 않습니다. 상세의 저장한 메모 요약은 직접 작성한 메모에 적용하며 영상·음성 내용은 분석하지 않습니다.

같은 파일을 다시 등록한 경우

파일 내용이 완전히 같은 이미지·동영상·PDF는 새 자료로 중복 저장하지 않습니다. 기존 자료에 새 키워드·카테고리와 선택한 모음 연결을 추가합니다. 기존 제목, 메모와 출처는 유지합니다.

크기나 형식이 바뀐 이미지는 별도 파일로 저장될 수 있습니다. 중복 저장 방지는 파일 내용 기준입니다. 비슷한 자료는 상세 화면의 유사 이미지 찾기로 비교할 수 있습니다. 같은 파일이 휴지통에 있다면 먼저 복원하세요.

여러 파일 중 일부만 실패하면 성공한 파일은 저장됩니다. 등록창에 실패 목록이 남으므로 원인을 확인한 뒤 자료 저장을 다시 누르면 실패한 파일만 재시도합니다.

링크 저장하기

  1. 오른쪽 위의 링크 저장을 누릅니다.
  2. 주소에 https:// 또는 http://로 시작하는 URL을 입력합니다.
  3. 제목, 키워드, 카테고리와 메모를 입력합니다.
  4. 링크 저장을 누릅니다.

이 버튼은 주소와 직접 입력한 정보를 저장합니다. 링크 저장만으로 페이지 내용이나 원본 파일을 보관하지는 않습니다. 원본 사이트에서 자료가 사라지면 링크만으로 내용을 복구할 수 없습니다. 직접 작성한 메모는 내용 분석으로 요약할 수 있습니다.

링크 안의 이미지 가져오기

  1. 보관 · 백업에서 링크 이미지 가져오기 허용을 켭니다. 기본은 꺼져 있습니다.
  2. 링크 저장 창에 공개 페이지 또는 직접 이미지 주소를 입력합니다.
  3. 링크 이미지 찾기를 누릅니다.
  4. 후보 목록에서 원하는 주소의 이미지 저장을 누릅니다.

선택한 이미지 원본과 입력한 분류·메모·출처를 자료함에 저장합니다. 사이트의 img·대표 이미지 주소만 찾으며 로그인, 접근 제한, 스크립트로 생성되는 이미지, 영상은 지원하지 않습니다. 저장할 권한이 있는 자료만 가져오세요. 로컬·내부망 URL은 차단합니다. 외부 사이트 접속이 필요하며 지원하지 않는 형식이나 연결 실패는 오류로 표시됩니다.

키워드와 카테고리 정하기

카테고리는 자료의 큰 묶음, 키워드는 자료의 구체적인 특징으로 사용하면 편리합니다.

  • 카테고리 예시: 환경, 인체, 의상, 학습.
  • 키워드 예시: 숲, 전신, 갑옷, 역광, 색채 이론.

한 자료에 여러 카테고리와 키워드를 붙일 수 있습니다. 입력할 때 쉼표로 구분하세요. 색채 이론처럼 공백이 포함된 이름도 사용할 수 있습니다. 카테고리와 키워드는 미리 만들지 않아도 자료를 저장할 때 생성됩니다.

미분류함은 키워드가 없는 자료를 모아 보여 줍니다. 카테고리만 지정한 자료도 키워드가 없다면 미분류함에 나타납니다.

자료 검색하기

검색창에는 제목, 파일명, 메모, 출처 URL, 키워드, 카테고리 또는 추출 텍스트에 있는 단어를 입력합니다. 여러 단어를 공백으로 구분하면 모든 단어가 들어 있는 자료를 찾습니다. PDF·이미지 안의 글자는 먼저 텍스트 추출 또는 OCR를 실행해야 검색됩니다.

예를 들어 숲 역광을 입력하면 자료 정보에 숲과 역광이 모두 포함된 자료가 표시됩니다. 두 단어가 서로 다른 항목에 있어도 검색됩니다.

상단의 이미지·동영상·PDF·링크 버튼으로 유형을 바로 선택할 수 있습니다. 숫자는 현재 검색 범위에서 각 유형에 해당하는 개수입니다. 키워드로 더 정확하게 찾으려면 상세 검색을 펼친 뒤 키워드 버튼을 누릅니다. 여러 버튼을 선택한 뒤 다음 조건을 사용합니다.

  • 키워드 모두 포함: 선택한 키워드가 전부 붙은 자료를 표시합니다.
  • 키워드 하나 이상: 선택한 키워드 중 하나라도 붙은 자료를 표시합니다.
  • 제외 키워드: 입력한 키워드가 붙은 자료를 숨깁니다. 여러 이름은 쉼표로 구분합니다.

예를 들어 숲, 역광 버튼을 선택하고 키워드 모두 포함을 사용하면 두 키워드가 모두 붙은 자료를 찾습니다. 제외 키워드에 사진을 입력하면 사진 키워드가 붙은 자료를 제외합니다. 제외 조건은 제목이나 메모의 단어가 아니라 자료에 붙은 키워드 이름에 적용됩니다.

왼쪽 카테고리와 전체 자료, 미분류함, 즐겨찾기, 휴지통은 검색 범위를 정합니다. 상세 검색에서 모든 자료, 이미지, 동영상, PDF, 문서, 묶음, 링크로 유형을 제한하고, 등록일 최신순, 등록일 오래된순, 자료 날짜 최신순, 자료 날짜 오래된순, 제목순으로 정렬할 수 있습니다.

자료가 보이지 않으면 전체 자료를 누르고 조건 초기화를 누르세요. 휴지통 자료는 휴지통에서 따로 찾습니다.

검색 조건 저장하기

  1. 검색어, 키워드, 제외 키워드, 카테고리와 유형·정렬을 설정합니다.
  2. 현재 조건 저장을 누르고 이름을 입력합니다.
  3. 다음에는 저장 검색 목록에서 이름을 선택합니다.

검색 조건을 저장하므로 조건에 맞는 새 자료도 표시됩니다. 같은 이름으로 저장하면 확인 후 기존 조건을 바꿉니다. 검색 조건 · 모음에서 이름 변경·열기·삭제를 할 수 있습니다. 검색을 삭제해도 자료는 유지됩니다. 삭제된 키워드가 검색 조건에 남아 있으면 결과가 없을 수 있으므로 새 조건으로 갱신하세요.

자료 수정과 즐겨찾기

  1. 자료 카드를 누르면 자료 상세가 열립니다.
  2. 제목, 키워드, 카테고리, 출처 URL과 메모를 수정합니다.
  3. 변경 저장을 누릅니다.

수정한 내용은 저장해야 반영됩니다. 상세 화면에서 키워드나 카테고리를 지우면 해당 자료와의 연결이 제거됩니다. 원본 이미지는 유지됩니다.

카드의 별 버튼이나 상세 화면의 즐겨찾기 버튼으로 즐겨찾기를 켜거나 끌 수 있습니다. 즐겨찾기 변경은 바로 저장됩니다. 왼쪽 즐겨찾기에서 모아 볼 수 있습니다. 출처가 있는 자료는 상세 화면의 출처 열기로 원래 사이트를 엽니다.

자료 상세 상단의 휴지통으로 이동을 누르면 목록에서 자료를 숨기고 원본·키워드·메모를 보관합니다. 이동 후 같은 버튼이 자료함으로 복원으로 바뀌므로 상세 화면에서 바로 되돌릴 수 있습니다. 상세에 입력한 수정 내용은 변경 저장 전까지 저장되지 않으며, 휴지통 이동·복원은 그 입력 내용을 덮어쓰지 않습니다. 원본 영구 삭제는 제공하지 않습니다.

여러 자료를 한꺼번에 정리하기

  1. 각 자료 카드의 선택 체크박스를 누릅니다. 현재 검색 결과 전체를 선택하려면 결과 모두 선택을 누릅니다.
  2. 선택 개수를 확인합니다.
  3. 일괄 편집 영역에 키워드나 카테고리를 쉼표로 구분해 입력합니다.
  4. 추가 또는 제거를 누릅니다.

추가는 기존 분류를 유지하면서 입력한 분류를 붙입니다. 제거는 입력한 분류의 연결만 제거하며 원본 파일을 삭제하지 않습니다. 일괄 즐겨찾기도 사용할 수 있습니다. 작업이 끝나면 선택 해제를 누르세요.

모음과 이미지 비교

  1. 자료 카드의 체크박스로 작업에 사용할 자료를 선택합니다.
  2. 새 모음을 누르고 프로젝트 이름을 입력합니다.
  3. 이후 왼쪽 모음 목록이나 상세 검색의 모음 목록에서 해당 모음을 선택합니다.

기존 모음에 자료를 추가하려면 전체 자료에서 새 자료를 선택하고 모음에 추가를 눌러 모음 이름을 입력합니다. 모음 안에서 자료를 선택하고 모음에서 제외를 누르면 모음의 연결만 제거합니다. 원본은 유지됩니다. 검색 조건 · 모음에서는 빈 모음 생성, 이름 변경, 열기와 삭제도 지원합니다. 모음당 최대 5,000개 파일(묶음 내부 포함)을 보관할 수 있습니다.

이미지 2~6개를 선택하고 이미지 비교를 누르면 나란히 확인할 수 있습니다. PDF와 링크는 이미지 비교 대상에서 제외합니다.

키워드와 카테고리 관리하기

왼쪽 아래의 키워드 · 카테고리 관리를 누릅니다. 새 이름을 입력하고 추가를 눌러 분류를 미리 만들 수 있습니다. 카테고리는 왼쪽 카테고리 제목 옆의 +로도 추가할 수 있습니다.

관리창에서 이름을 변경할 수 있습니다. 이미 있는 이름으로 변경하면 확인 후 두 분류를 병합합니다. 해당 분류가 붙은 자료들의 연결도 함께 정리됩니다.

관리창에서 분류를 삭제하면 그 이름과 모든 자료의 연결이 제거됩니다. 자료와 원본 파일은 삭제되지 않습니다. 유일한 키워드가 제거된 자료는 미분류함에 나타납니다.

제목·내용으로 자동 분류하기 (0.6.0)

키워드 · 카테고리 관리에서 키워드를 추가하고 텍스트 규칙을 누르세요. 예를 들어 ‘회의 자료’ 키워드에 다음과 같이 설정합니다.

  1. 모드를 추천만 또는 자동 적용으로 선택합니다. 기본은 끄기입니다.
  2. 제목, 파일명, 메모, 본문 · 추출 텍스트 중 문구를 찾을 항목을 선택합니다.
  3. 찾을 문구를 한 줄에 하나씩 입력합니다. 예: 회의록, 회의 결과. 최대 30개, 각 100자입니다.
  4. 문구 중 하나라도 포함 또는 모든 문구 포함을 선택하고 규칙 저장을 누릅니다.
  5. 새로 등록하는 자료에는 자동으로 적용됩니다. 기존 자료는 분류 확인함에서 범위를 선택하고 이 범위로 다시 분류를 누릅니다.

텍스트 규칙은 이미지 사례 10개나 모델 다운로드가 필요 없습니다. 제목·메모·본문에 지정한 문구가 들어 있는지 로컬에서 확인하며, 의미를 추론하는 AI 분류는 아닙니다. 대소문자·전각 문자·연속 공백과 줄바꿈 차이를 정규화합니다. 모든 문구 조건은 선택한 여러 항목·페이지에 나뉘어 있어도 일치합니다. 문구 하나는 한 항목 또는 한 페이지 안에 있어야 합니다.

DOCX·XLSX·PPTX·TXT 등의 본문은 업로드 시 추출한 텍스트를 사용합니다. PDF는 저장된 추출 결과가 없으면 분류 중 텍스트를 추출하며, 자동 요약을 켜지 않아도 본문 규칙을 사용할 수 있습니다. 이미지·스캔 PDF는 먼저 내용 분석 → OCR을 실행하세요. 텍스트 추출·OCR 작업 완료 후 켜진 분류 규칙도 적용합니다. 링크 웹페이지의 본문이나 동영상 음성을 가져오지는 않습니다. 추출 지원 범위 밖의 내용은 일치 여부를 판단할 수 없습니다.

묶음은 공통 제목·메모와 각 파일의 제목·파일명·본문을 함께 보고 내부 파일별로 분류합니다. 카테고리는 기존처럼 직접 지정하며 이 규칙은 키워드를 붙입니다. 분류 확인함에 일치한 문구와 본문 페이지를 표시하며 승인·거절할 수 있습니다. 수동 키워드와 승인·거절 기록은 재분류해도 보존합니다. 확인 전 결과만 새 규칙으로 갱신합니다. 제목·메모·추출 텍스트를 수정했거나 규칙을 바꾼 경우에도 해당 자료를 다시 분류하세요.

이미지 유사도 모드와 텍스트 규칙 모드는 별개입니다. 둘 다 일치하면 텍스트 규칙의 모드를 우선합니다. 텍스트가 일치하지 않으면 켜진 이미지 유사도 규칙으로 판단합니다. 규칙을 끄면 새 자료에는 사용하지 않으며 기존 미확정 결과는 재분류할 때 갱신합니다. 텍스트 규칙·일치 근거·문서 분류 이력이 포함된 백업은 0.6.0 이상에서 복원하세요.

확정 이미지 10개의 의미

관리창의 확정 이미지 3/10개는 해당 키워드를 직접 붙이거나 분류 확인함에서 승인한 이미지가 3개라는 뜻입니다. 서로 다른 이미지 10개부터 자동 분류 활성화 조건을 충족합니다. 링크와 휴지통 이미지는 이 개수에서 제외합니다.

10개는 저장 상한이 아닙니다. 11개 이상도 계속 저장할 수 있습니다. 동영상·PDF와 확인 전 자동 결과도 사례 수에서 제외합니다. 10개가 쌓여도 사용자가 분류 모드를 켜기 전에는 자동으로 키워드를 붙이지 않습니다.

자동 분류 켜기와 결과 확인

  1. 보관 · 백업에서 로컬 분석 모델 준비를 누릅니다. 최초 약 88.6 MB를 내려받습니다. 이미지 원본을 외부에 보내지는 않습니다.
  2. 키워드 · 카테고리 관리에서 확정 이미지가 10개 이상인 키워드의 모드를 선택합니다.
  3. 처음에는 추천만으로 시작합니다. 이후 결과를 확인해 자동 적용 또는 끄기로 바꿀 수 있습니다.
  4. 새 이미지를 등록하거나 분류 확인함에서 범위를 선택해 이 범위로 다시 분류, 선택 영역의 선택 자료 분류를 실행합니다.
  5. 분류 확인함에서 대상 이미지, 제안 키워드와 유사 사례를 확인하고 승인 또는 거절을 누릅니다.

추천만은 확인 전 키워드를 붙이지 않습니다. 자동 적용은 기준을 넘으면 키워드를 붙이지만 승인 전까지 확정 사례에는 포함하지 않습니다. 자동으로 붙인 키워드는 카드에 자동으로 표시합니다. 승인하면 확정 사례가 되고, 거절하면 자동 키워드를 제거합니다. 거절한 자료·키워드 조합은 재분석으로 다시 붙이지 않습니다. 승인·거절 기록은 분류 확인함의 승인·거절 기록에서 볼 수 있습니다.

유사도 기준의 기본값은 0.9이며 0.5~1로 조정합니다. 낮추면 더 많은 결과를 제안할 수 있고, 높이면 더 비슷한 자료만 제안합니다. 점수는 CLIP 이미지 특징의 유사도이며 정확도 확률이 아닙니다. 10개 역시 정확도 보장이 아닙니다. 실제 자료에서 결과를 확인해 기준을 조정하세요.

설정은 변경 시 자동 저장하며 각 키워드의 저장 버튼으로도 저장할 수 있습니다. 숫자 입력 직후 관리창을 닫거나 Esc를 눌러도 저장을 마친 뒤 닫습니다. 분류 실행은 진행 중인 설정 저장이 끝난 뒤 시작합니다. 분석 중에는 설정을 바꿀 수 없습니다.

설정만 바꾸면 기존 결과는 유지합니다. 재분류를 실행하면 지정한 이미지의 확인 전 자동 결과를 새 설정으로 갱신합니다. 추천만에서 자동 적용으로 바꾸면 기존 추천도 키워드로 붙일 수 있습니다. 자동 적용에서 추천만으로 바꾸면 확인 전 자동 키워드를 제거하고 추천으로 돌립니다. 기준을 높여 유사도가 기준에 못 미치거나 모드를 끈 키워드의 확인 전 결과는 재분류할 때 제거합니다. 수동 키워드와 승인·거절 기록은 보존합니다. 제거한 자동 결과는 거절로 기록하지 않으므로 나중에 기준을 낮추면 다시 추천될 수 있습니다.

확정 이미지가 10개 미만으로 줄면 새 자동 분류를 일시 중단하고 기존 결과를 보존합니다. 모드를 끄고 재분류하면 해당 범위의 확인 전 결과를 정리할 수 있습니다. 분석 실패 시 이전 자동 결과도 보존하며, 원본 저장과 수동 분류를 막지 않습니다.

자료 분류 범위 지정

분류 확인함의 자료 분류 범위에서 대상을 고릅니다. 기본은 미분류 자료 · 키워드 없음입니다. 키워드·카테고리가 모두 없는 자료, 분류 이력 없는 새 자료, 전체 자료, 현재 검색 결과, 현재 선택한 자료를 고를 수 있습니다.

자료 유형, 키워드 조건, 카테고리 조건, 최근 등록 시간을 함께 지정할 수 있습니다. 예를 들어 전체 자료에서 유형을 문서, 카테고리를 업무, 최근 등록 시간을 6으로 설정하면 최근 6시간 안에 등록한 업무 문서에만 적용합니다. 키워드 조건은 대상 자료를 고르는 필터이며, 분류 자체는 현재 켜진 모든 키워드 설정으로 실행합니다. 텍스트 규칙은 모든 자료 유형에, 이미지 유사도는 이미지에만 적용합니다. 휴지통은 제외합니다.

대상 확인으로 내부 파일 개수를 확인한 뒤 이 범위로 다시 분류를 누릅니다. 묶음은 내부 파일별로 처리하며 한 번에 최대 5,000개입니다. 원본과 수동 키워드·승인·거절 기록은 보존합니다. 설정 변경 후 기존 자료를 다시 평가하려면 새 자료 범위 대신 전체·선택·키워드·카테고리 범위를 사용하세요.

분석 진행 상태

분석 중에는 자료함 상단과 열린 관리창에 큰 상태 배너가 나타납니다. 회전 표시, 진행 막대, 처리 완료 3 / 10개 · 30%처럼 처리 개수를 표시합니다. 자료 개수 기준이며 분석 정확도나 남은 시간의 비율은 아닙니다. 모델 준비는 다운로드 진행률을 알 수 없어 개수와 퍼센트 대신 준비 중으로 표시합니다.

배너는 페이지와 함께 스크롤됩니다. ×(분석 표시 닫기)를 누르면 큰 배너를 숨기고 상단의 작은 진행 상태 버튼만 남깁니다. 상태 버튼을 누르면 다시 펼칩니다. 닫아도 분석은 계속되며 완료·실패 알림이 표시됩니다. 같은 탭에서는 새로고침 후에도 접은 상태가 유지됩니다. 상세·분류 확인함·보관 창에서도 상태 버튼으로 펼칠 수 있습니다. 관리창을 닫고 자료를 정리해도 서버의 분석은 계속됩니다. 완료 후에는 완료 표시가 남고, 실패 항목이 있으면 실패 이유를 표시합니다. 서버 연결이 끊기면 완료로 표시하지 않고 분석 상태 확인 중단으로 안내하며 자동으로 연결을 다시 확인합니다. 다른 브라우저 탭을 보고 있어도 탭 제목에서 분석 중 상태를 확인할 수 있습니다.

유사 이미지 찾기

이미지의 자료 상세에서 유사 이미지 찾기를 누릅니다. 다른 활성 이미지 중 유사한 자료를 최대 30개 표시합니다. 결과를 누르면 그 자료의 상세 화면을 엽니다. 모델을 먼저 준비해야 하며 동영상·PDF·링크·휴지통 자료는 검색 대상에서 제외합니다. 유사하다는 이유만으로 중복 삭제나 병합을 수행하지 않습니다.

PDF와 이미지 내용 분석

  1. 자료의 자료 상세를 엽니다.
  2. PDF는 텍스트 추출 · 요약, 이미지와 스캔 PDF는 이미지 · 스캔 PDF OCR를 누릅니다.
  3. 메모를 요약하려면 변경한 메모를 먼저 저장하고 텍스트 추출 · 요약을 누릅니다.
  4. 결과의 근거 페이지를 선택하면 추출 텍스트를 확인할 수 있습니다. 검색 결과에서 자료를 열면 검색어와 가장 많이 일치하는 추출 페이지를 먼저 선택합니다. PDF는 PDF 페이지 열기로 원본 페이지도 엽니다.

요약은 원문 문장 중 최대 5개를 뽑는 방식입니다. 생성형 AI가 새 설명을 작성하는 기능은 아닙니다. 추출 텍스트와 요약은 사용자 메모와 분리해 저장합니다. 요약할 문장이나 읽을 텍스트가 없으면 결과에 표시합니다.

OCR 오류는 추출 텍스트 수정 칸에서 고친 뒤 추출 텍스트 수정 저장을 누릅니다. 요약이 켜진 결과는 수정된 텍스트로 다시 요약합니다. 키워드 후보 중 필요한 항목을 체크하고 선택 키워드 추가를 누르면 수동 키워드로 저장합니다. 후보는 단어 빈도 기준이므로 한국어 조사 등이 붙을 수 있습니다.

Windows OCR는 설치된 언어팩을 사용합니다. 현재 PC는 한국어 OCR를 확인했으며 영어 전용 OCR는 영어 언어팩이 필요합니다. 스캔 PDF OCR는 최대 30페이지, 추출 텍스트는 자료당 최대 50만 자까지 지원합니다.

새 자료 자동 요약과 OCR

보관 · 백업에서 새 자료 자동 요약, 새 이미지 · 스캔 PDF 자동 OCR, 자동 OCR 언어를 각각 설정합니다. 기본은 꺼져 있습니다. 요약을 켜면 새 PDF의 텍스트와 새 자료의 메모를 자동 분석합니다. 이미지 속 글자와 스캔 PDF를 읽으려면 OCR도 켭니다. OCR만 켜면 텍스트를 추출하며 요약은 만들지 않습니다. 기존 자료는 상세 화면에서 직접 분석하세요.

휴지통과 자료 복원

  1. 자료를 선택하고 일괄 편집 영역의 휴지통을 누릅니다.
  2. 확인창에서 내용을 확인하고 이동합니다.
  3. 되돌리려면 왼쪽 휴지통을 엽니다.
  4. 되돌릴 자료를 선택하고 복원을 누릅니다.

휴지통에서도 원본과 자료 정보는 보관됩니다. 현재는 영구 삭제 기능이 없으므로 휴지통으로 옮겨도 저장 공간은 줄지 않습니다.

백업 저장하기

  1. 왼쪽 아래의 보관 · 백업을 누릅니다.
  2. 백업 일정과 저장 위치에서 백업 폴더 전체 경로를 확인합니다. 바꾸면 백업 설정 저장을 누릅니다.
  3. 백업 ZIP 만들기를 누르고 진행 표시가 완료로 바뀌면 해당 폴더의 ZIP을 확인합니다. 완료한 ZIP 다운로드로 브라우저의 다운로드 폴더에도 저장할 수 있습니다.
  4. 복구용 ZIP을 다른 디스크에도 복사해 둡니다.

ZIP에는 원본, 미리보기, 키워드, 카테고리, 메모, 즐겨찾기와 휴지통 자료가 포함됩니다. 메타데이터 JSON 저장은 자료 정보만 내보냅니다. 원본 파일이 없으므로 JSON만으로 전체 자료함을 복구할 수 없습니다.

저장 검색, 모음, 분류 설정·확인 기록과 내용 분석 결과도 ZIP에 포함됩니다. 분석 모델은 별도 파일이므로 다른 PC에서 사용할 때 로컬 분석 모델 준비를 다시 실행하세요.

백업 ZIP과 압축 해제한 총량은 각각 최대 50 GiB이며, 내부 파일은 최대 50,000개입니다. ZIP 생성·전송·복원 업로드는 나누어 처리합니다. 복원 형식 검사는 원본 파일 하나씩 수행하며 기존 이미지·PDF 50 MB, 동영상 200 MB 한도를 유지합니다. 복원에는 업로드한 ZIP, 새 자료, 현재 자료함 안전 백업을 보관할 여유 공간이 필요합니다.

앱 실행 중 하루 한 번 자동 백업을 켜고 설정을 저장하면 첫 백업을 시작합니다. 마지막 성공 후 24시간마다 다시 실행합니다. 앱이 꺼져 있으면 다음 실행 때 확인하고, 분석 중에는 완료 후 실행합니다. 실패하면 오류를 표시하고 최대 한 시간에 한 번 재시도합니다. 자동 백업은 기본적으로 꺼져 있습니다. 백업 파일은 자동 삭제하지 않으므로 저장 공간을 관리하세요. 백업 중에는 원본 변경 요청이 잠시 대기할 수 있습니다.

자동 백업 설정과 저장 경로는 해당 PC에만 보관하며 자료함 ZIP으로 옮기지 않습니다. 다른 PC에서는 저장 위치를 다시 지정하세요. 같은 디스크의 백업만으로 디스크 고장에 대비할 수 없으므로 필요한 ZIP을 다른 디스크에도 보관하세요.

백업으로 자료함 복원하기

백업 복원은 현재 자료함을 백업 내용으로 교체합니다. 두 자료함을 합치는 기능이 아닙니다. 복원할 ZIP과 교체 내용을 먼저 확인하세요.

  1. 보관 · 백업을 엽니다.
  2. 백업 ZIP 선택을 누르고 RefArchive에서 만든 ZIP을 선택합니다.
  3. 확인창의 파일명을 확인한 뒤 확인을 누릅니다.
  4. 복원이 끝나면 자료 목록과 메모를 확인합니다.

파일 검증에 실패하면 현재 자료함을 교체하지 않습니다. 교체 직전 자료함은 data/backups/before-restore-*.zip에 안전 백업으로 보관하고, 이전 폴더도 data/previous-*/에 남깁니다. 이전 상태로 되돌리려면 해당 안전 백업 ZIP을 같은 방법으로 복원하세요. 안전 백업과 이전 폴더는 자동 삭제하지 않습니다.

저장 위치와 접속 문제

배포본의 기본 자료 위치는 %LOCALAPPDATA%\RefArchive\data\library이며 모델은 %LOCALAPPDATA%\RefArchive\models에 저장됩니다. 개발용 소스는 프로젝트의 data\library와 .models를 사용합니다. 보관 · 백업에서도 현재 원본 보관 위치를 확인할 수 있습니다. 자료는 브라우저 탭을 닫거나 서버를 종료해도 PC에 남습니다. 복원 설명의 data/는 각 실행 방식의 데이터 폴더를 뜻합니다.

주소가 열리지 않으면 RefArchive 바로가기를 다시 실행하세요. 배포본 실행 실패 시 오류창과 %LOCALAPPDATA%\RefArchive\data\logs를 확인합니다. 개발용 소스는 start.cmd로 실행하고 data/runtime-error.log를 확인하세요. 127.0.0.1은 지금 사용하는 PC를 뜻하므로 다른 PC나 휴대폰에서는 이 주소로 접속할 수 없습니다.

개발용 소스에서 Python 설치 오류가 나오면 Python 3.12 이상을 확인합니다. 라이브러리 설치 오류가 나오면 인터넷 연결을 확인합니다. 배포본에는 이러한 설치 과정이 없습니다. 파일 저장이 실패하면 등록창의 실패 목록에서 파일 크기, 지원 형식과 손상 여부를 확인하세요.

배포본은 기본 포트가 사용 중이면 빈 포트를 자동으로 선택합니다. 화면이 열리지 않으면 바로가기를 다시 실행하고, 실행 오류창에 표시된 기록을 확인하세요.

현재 제공하지 않는 기능

  • 외부 링크의 영상 다운로드, 영상 내용·음성 분석, 움직이는 이미지 지원.
  • 로그인·접근·다운로드 제한을 우회하는 수집.
  • 생성형 AI 요약, 정교한 한국어 형태소 분석.
  • 클라우드 동기화, 외부 접속, 브라우저와 분리된 독립 데스크톱 창.

설치와 다른 PC로 자료를 옮기는 방법은 설치 · 배포 안내에서 확인할 수 있습니다.

0.4.0 업데이트와 백업 호환

이전 자료함은 첫 실행에서 필요한 경우 새 형식으로 변환합니다. 변환 전 SQLite 사본은 데이터 폴더의 backups/migration-v1-*.sqlite3 또는 migration-v2-*.sqlite3·migration-v3-*.sqlite3·migration-v4-*.sqlite3에 보관됩니다. 원본 파일·수동 분류·메모·기존 자료 모음을 유지합니다. 묶음 대표 파일과 1 GiB를 넘는 백업은 0.4.0 이상으로 여세요. 이전 앱으로 되돌릴 때는 업데이트 전에 만든 ZIP 백업을 사용하세요. 동영상도 ZIP에 포함하며 백업·복원 한도는 각각 50 GiB입니다.

묶음 대표 파일·순서·개별 분리

묶음 상세에서 파일을 선택한 뒤 대표로 지정, 앞으로, 뒤로를 누릅니다. 변경은 즉시 저장됩니다. 순서를 바꾸어도 지정한 대표 파일은 유지됩니다. 대표 파일은 이미지뿐 아니라 동영상·PDF·링크도 선택할 수 있으며 해당 파일의 미리보기를 사용합니다.

이 파일만 분리는 선택한 파일만 별도 카드로 만듭니다. 원본과 키워드·카테고리·개별 메모·분석 결과를 유지하고, 공통 제목·출처·메모를 분리한 파일의 메모에 덧붙입니다. 편집 중인 내용은 먼저 변경 저장을 누르세요. 메모 한도를 넘으면 분리하지 않고 오류를 표시합니다. 대표 파일을 분리하면 남은 첫 파일이 대표가 됩니다. 파일 하나가 남아도 묶음은 유지하며 마지막 파일을 분리하면 빈 묶음을 제거합니다.

유사 중복 비교와 정리

보관 · 백업 → 유사 중복 검사를 누릅니다. 별도 모델·인터넷 없이 화면의 형태와 색상을 비교해 크기나 압축만 다른 것으로 보이는 이미지를 찾습니다. 이미지 5,000개, 후보 200쌍까지 검사합니다. 휴지통·동영상·PDF·링크와 정보가 적은 이미지는 제외하며 잘라내기·회전·색상 수정은 놓칠 수 있습니다. 후보가 없다는 것이 중복이 없다는 보장은 아닙니다.

검사 결과 보기에서 두 이미지를 비교하고 이미지를 누르면 원본을 새 탭으로 엽니다. 지울 쪽의 이 파일만 휴지통으로를 누르고 확인합니다. 묶음 안에 있어도 그 파일만 분리한 뒤 이동합니다. 다른 파일은 유지합니다. 휴지통에서 복원할 수 있지만 이전 묶음에 자동으로 다시 연결하지는 않습니다. 후보는 현재 실행 중에만 유지하므로 재실행 후에는 다시 검사하세요.

ZIP 업데이트 확인·실행 진단·다른 PC 점검

보관 · 백업 → 실행 상태와 업데이트에서 실행 버전과 시작 시각을 확인합니다. ZIP을 직접 전달받은 경우 새 폴더에 압축을 풀고 받은 버전 정보 확인에서 그 폴더의 업데이트 정보.json을 선택하세요. 새 버전·같은 버전·이전 버전을 구분해 안내합니다. 파일을 받기 전에 원격으로 새 배포를 알아내거나 업데이트를 자동 설치하는 기능은 없습니다.

업데이트 전 ZIP 백업을 만든 뒤 프로그램 종료를 누르고 새 폴더의 RefArchive.exe를 실행하세요. 같은 PC·Windows 계정의 배포본끼리는 같은 자료 위치를 사용하므로 다시 업로드하지 않아도 됩니다. _internal을 포함한 폴더 전체를 유지하세요. 이전 프로그램 폴더는 새 버전에서 자료를 확인한 뒤 정리합니다.

진단 보고서 저장은 버전·운영체제·자료 종류별 개수·DB 정상 여부·누락 파일 수·오류 종류·백업 시각·점검 결과를 JSON으로 저장합니다. 제목·메모·원본·출처 URL·파일 경로·접속 토큰·실행 로그 원문은 포함하지 않고, 외부로 전송하지 않습니다. 보낸 사람에게 전달하려면 내용을 확인한 뒤 직접 전달하세요.

다른 PC 배포 점검표를 펼치고 실제로 시험한 항목만 통과 또는 문제 있음으로 기록합니다. 초기에는 시험 자료로 실행·업로드·검색·묶음·백업 복원·재실행을 확인하고, 업데이트 시험에는 업데이트 전후 원본·키워드·묶음이 남아 있는지도 확인하세요. 점검 결과는 그 PC에 저장되며 진단 보고서에 함께 들어갑니다.

이 안내는 인터넷이나 프로그램 실행 없이도 읽을 수 있습니다. 파일을 열면 기본 브라우저에서 표시됩니다.
