링크 이미지 가져오기

공개 페이지의 img·대표 이미지 주소와 직접 이미지 링크를 지원합니다. 로그인·접근 제한·영상·스크립트로 생성되는 페이지는 지원하지 않습니다. 저장할 권한이 있는 자료만 선택하세요.

유사 중복 비교

중복 판정은 후보입니다. 두 원본을 비교하세요. 선택한 파일만 휴지통으로 옮기며 복원할 수 있습니다. 분리한 파일은 묶음에 자동으로 다시 연결되지 않습니다.

텍스트 분류 규칙

문구가 포함된 자료에 이 키워드를 추천하거나 적용합니다. 이미지 사례 10개나 분석 모델 없이 사용할 수 있습니다.

문구를 찾을 항목

예: ‘회의록’ 키워드에 제목의 ‘회의록’, ‘회의 결과’ 중 하나를 찾도록 설정하세요. 모든 문구 조건은 선택한 항목·페이지에 나뉘어 있어도 일치합니다. 본문은 저장된 추출 텍스트를 사용하며, PDF에 없으면 로컬로 추출합니다. 스캔 자료는 먼저 OCR을 실행하세요. 링크 웹페이지나 동영상 음성은 읽지 않습니다.

저장 후 새 자료부터 적용됩니다. 기존 자료나 제목·메모·본문을 수정한 자료는 분류 확인함에서 범위를 선택해 다시 분류하세요. 이미지 규칙과 함께 일치하면 텍스트 규칙의 모드를 우선합니다.

카테고리 분류 기준

카테고리 이름과 제목·파일명·본문을 비교합니다. 확실한 후보 하나만 자동 배정하고, 후보가 비슷하면 확인함에 남깁니다.

직접 지정하거나 승인한 자료를 비교 사례로 사용합니다. 같은 묶음은 한 사례이며 확인 전 자동 결과는 제외합니다. 스캔 자료는 OCR을 켜거나 먼저 실행하세요. 영상의 장면·음성과 링크 본문은 분석하지 않습니다.

새 업로드부터 적용합니다. 기존 자료와 수정한 자료는 분류 확인함에서 다시 분류하세요. 직접 지정·승인·거절한 결과는 유지합니다.
